# Ibex WhatsApp Sales Agent

## Description
Ibex WhatsApp Sales Agent is an AI-powered SaaS platform that helps businesses communicate and convert leads via WhatsApp. Designed for small and medium businesses across various industries, it includes CRM capabilities, AI-driven automated responses, and integration with the WhatsApp Cloud API.

## Features (MVP)
- **Authentication**: Email/password and Google login with JWT.
- **Business Onboarding**: Collect business details like name, industry, WhatsApp number, and products.
- **AI WhatsApp Integration**: Automate customer interactions via WhatsApp.
- **CRM for Sales Pipelines**: Organize leads and manage conversations with drag-and-drop functionality.
- **Database**: PostgreSQL with `pgvector` for AI embeddings.

## Tech Stack
- **Frontend**: Next.js (React/TypeScript/Tailwind CSS).
- **Backend**: NestJS with Prisma ORM.
- **Database**: PostgreSQL + Redis (queue).
